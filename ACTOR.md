# Instagram Following Hybrid Actor

Commercial tiers:

- Free: public profiles only, reduced default limit
- Plus: cookies supported, improved reliability
- VIP: larger batch support, richer diagnostics, higher limits

This actor is designed to be original and publishable on Apify.

The implementation favors:

- deterministic input normalization
- structured per-target diagnostics
- partial success over hard failure
- explicit handling for private, login-required, and blocked states
