# Security Policy

## Supported Versions

This repository supports the current `main` branch only.

## Reporting a Vulnerability

If you find a security issue, report it privately to the repository owner or maintainers before opening a public issue.

Please include:

- affected file or endpoint
- reproduction steps
- expected vs actual behavior
- impact assessment

## What We Treat as Security Issues

- secret exposure
- credential leakage
- unsafe persistence of cookies or tokens
- unauthorized data export
- injection or code execution risks
- dependency or supply-chain compromise

## Response Target

We aim to acknowledge reports quickly and prioritize fixes that reduce exposure of secrets, personal data, and public repository misuse.
